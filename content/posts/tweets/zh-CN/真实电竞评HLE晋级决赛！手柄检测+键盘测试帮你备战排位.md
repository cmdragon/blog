打游戏最怕的就是关键时刻操作失灵！手柄检测帮你全面诊断手柄状态。

### 怎么用？

1. 用USB线或蓝牙连接手柄到电脑
2. 打开浏览器访问 [手柄检测](https://tools.cmdragon.cn/zh/apps/gamepad-detector)
3. 按压各个按键，实时查看检测结果
4. 测试摇杆灵敏度，检查是否有漂移
5. 测试扳机深度和震动反馈

### 手柄检测功能一览

| 检测项目 | 功能说明 | 解决的问题 |
|---------|---------|-----------|
| 按键测试 | 实时显示每个按键状态 | 按键失灵/粘连 |
| 摇杆测试 | 显示XY轴数值和可视化 | 摇杆漂移/不灵敏 |
| 扳机测试 | 显示扳机按压深度 | 扳机无响应 |
| 震动测试 | 触发手柄震动反馈 | 震动功能异常 |
| 连接状态 | 显示连接方式和延迟 | 蓝牙/USB连接问题 |

### 常见手柄问题及解决方法

| 问题现象 | 可能原因 | 解决方案 |
|---------|---------|---------|
| 按键无响应 | 接触不良/驱动问题 | 重新插拔/更新驱动 |
| 摇杆自动偏移 | 漂移故障 | 校准摇杆或更换 |
| 蓝牙频繁断连 | 干扰/距离过远 | 减少干扰源/靠近连接 |
| 延迟高 | USB供电不足 | 换USB口/用有线模式 |
| LT/RT不灵敏 | 扳机弹簧老化 | 更换扳机模块 |

## 三、工具2：键盘测试 - 每个按键都要靠谱

👉 [立即体验 键盘测试](https://tools.cmdragon.cn/zh/apps/keyboard-tester)

PC游戏玩家，键盘就是你的武器！键盘测试帮你确认每个按键都正常工作。

### 怎么用？

1. 打开 [键盘测试](https://tools.cmdragon.cn/zh/apps/keyboard-tester)
2. 逐个按下键盘上的按键
3. 对应按键会在屏幕上高亮显示
4. 没有高亮的按键就是有问题的
5. 测试N键无冲，同时按多个键看是否全部响应

### 键盘检测重点项目

| 检测项目 | 说明 | 对游戏的影响 |
|---------|------|-------------|
| 单键响应 | 每个按键是否触发 | 基本操作 |
| N键无冲 | 同时按多键是否全部响应 | 连招/快速操作 |
| 按键粘连 | 松开后是否还在触发 | 误操作 |
| 重复触发 | 按住是否稳定重复 | 走路/持续施法 |
| 组合键 | Shift/Ctrl组合是否正常 | 快捷键 |
