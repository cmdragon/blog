## 四、自动泊车技术vs狗狗"驾驶"

### 自动泊车科普

| 知识点 | 说明 |
|--------|------|
| 原理 | 通过超声波雷达+摄像头识别车位，自动控制方向盘 |
| 速度 | 通常5km/h以下低速完成 |
| 限制 | 驾驶员必须随时准备接管 |
| 法规 | 驾驶员必须在驾驶位，随时关注车辆状态 |
| 处罚 | 让宠物坐驾驶位属于妨碍安全驾驶 |

### 为什么不能让狗"开车"？

| 风险 | 说明 |
|------|------|
| 无法接管 | 狗无法在紧急情况下接管车辆 |
| 误触按钮 | 狗可能踩到油门或碰到换挡杆 |
| 遮挡视线 | 狗在驾驶位会影响驾驶员视线 |
| 法律违规 | 属于妨碍安全驾驶行为 |

> 🔑 **安全提示**：自动泊车只是辅助功能，驾驶员必须始终在驾驶位并保持注意力。让宠物坐驾驶位不仅违法，更可能造成严重事故！
