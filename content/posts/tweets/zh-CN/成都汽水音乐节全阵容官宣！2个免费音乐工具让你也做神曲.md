### Strudel基础代码模板

| 风格 | 代码示例 | 效果 |
|------|---------|------|
| 简单节拍 | `sound("bd hh sd hh")` | 标准four-on-the-floor |
| 民谣节奏 | `sound("bd ~ sd ~ bd ~ sd ~")` | 民谣吉他感 |
| 摇滚鼓点 | `sound("[bd bd] [sd sd] [bd bd] [sd sd]")` | 摇滚鼓点 |
| 说唱节拍 | `sound("bd [~ bd] sd [~ sd]")` | 嘻哈节奏 |
| 复古迪斯科 | `sound("bd hh sd [hh bd] hh sd hh bd")` | 80年代迪斯科 |
| 电子氛围 | `sound("bd ~ ~ ~ sd ~ ~ ~")` | 电子ambient |

### 进阶音乐创作技巧

| 技巧 | 代码示例 | 效果 |
|------|---------|------|
| 加和弦 | `note("c3 e3 g3").sound("sawtooth")` | 合成器和弦 |
| 节奏变化 | `sound("bd <hh sd> hh sd")` | 节奏切换 |
| 音色叠加 | `stack(sound("bd"), sound("hh"))` | 多层叠加 |
| 速度控制 | `sound("bd sd").slow(2)` | 慢一倍 |
| 反向节拍 | `sound("bd sd").rev()` | 节奏反转 |
| 渐进效果 | `sound("bd sd").fade(4)` | 渐入渐出 |

### 音乐节风格创作参考

#### 民谣风格（毛不易风）

```
stack(
  sound("bd ~ ~ ~ sd ~ ~ ~"),
  note("c3 ~ e3 ~ g3 ~ e3 ~").sound("piano"),
  sound("~ [~ cp] ~ [~ cp]")
).slow(0.5)
```

**效果**：温柔民谣基调，钢琴和弦+轻柔鼓点

#### 摇滚风格（痛仰风）

```
stack(
  sound("[bd bd] [bd sd] [bd bd] [sd sd]"),
  note("e3 e3 g3 e3").sound("distort"),
  sound("cp ~ cp ~")
)
```

**效果**：强烈摇滚节奏，失真吉他+密集鼓点

#### 说唱风格（GAI风）

```
stack(
  sound("bd [~ bd] sd [~ sd]"),
  note("a2 ~ a2 ~").sound("bass"),
  sound("hh hh hh hh").gain(0.3)
)
```

**效果**：嘻哈节奏，重低音+密集踩镲

#### 电子舞曲（电音节风）

```
stack(
  sound("bd hh sd hh bd hh sd [hh bd]"),
  note("c3 <e3 g3> <a3 c3>").sound("supersaw"),
  sound("~ ~ cp ~")
)
```

**效果**：电子节拍，合成器音色+经典舞曲结构
